# The-Long-War-40k-homebrew
BSData files for building The Long War army lists.
Tested in Newrecruit

All files are based off material referenced from [https://drive.google.com/drive/](https://drive.google.com/drive/folders/1VBC2H49xydk8lPxgAjTY9sFtNmHQefp4)


## Submitting Issues
If you see any rules discrepancies while building a list, please submit a list of identified problems in the issue tracker. Please collect identified problems within a faction's roster into a single issue, and avoid including multiple factions in the same issue. Current development is still focusing on initial build of each faction file, so fixing RaW errors will get prioritized over RaI errors, as RaI will also need debate to come to a consensus on.
